# Last Pass

An endless slingshot climber for mobile web. Drag anywhere, release to sling.
Three slings per landing, each weaker than the last — land to reload. No
deaths: the only enemy is the long way down.

**Play**: serve this folder over HTTP (`python3 -m http.server`) and open it
on a phone, or open `index.html` in a desktop browser (mouse = one thumb).

- `index.html` — the whole game. No build step, no dependencies.
- `CLAUDE.md` — design decisions, tuning constants, and roadmap.

Prototype history (golf mode, corridor dungeon, and friends) lives in the
`last-pass-game` sibling repo.
